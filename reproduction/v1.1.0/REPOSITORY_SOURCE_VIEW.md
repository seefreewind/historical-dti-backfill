# Source view

This repository directory contains the v1.1.0 code, pinned environment, provenance, documentation and validation evidence. It omits the large expected-data directory and workbook from Git storage. For execution, download historical_dti_backfill_v1.1.0.zip from the v1.1.0 release and extract it into an empty directory. That complete archive has the FILE_MANIFEST and SHA256SUMS expected by the reproduction instructions. Do not treat this partial source view as the full package or run its package-wide checksum list here.

Archive and record: https://github.com/seefreewind/historical-dti-backfill/releases/tag/v1.1.0 ; Zenodo https://doi.org/10.5281/zenodo.24390323 (reserved until record publication).
