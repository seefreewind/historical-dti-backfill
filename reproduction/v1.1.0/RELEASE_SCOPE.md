# Release scope

The project owner instructed completion of v1.1.0 public archiving on 20 November 2026. This authorizes publishing the previously reviewed code/data payload under its stated separate licenses. It is not a new assertion about individual author contributions, AI model identity, ethics documents or manuscript acceptance. Historical candidate-status statements inside validation evidence describe the time of those tests.

The supplementary DOCX is excluded because its editorial acceptance is a separate author-review item. The frozen supplementary workbook remains data. The raw ChEMBL databases and archives are external inputs, not bundled. Full activity-level evidence, expected data, software notices and validation outputs are included. Scientific functions and data retain their original source hashes. Only release documentation/metadata/manifests are finalized here.
